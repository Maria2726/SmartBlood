# SmartBlood MVP — Flutter-прототип

Симулятор пользовательского пути портативного анализатора крови
(6 показателей + ИИ-рекомендации). Без реального Bluetooth: измерение
имитируется генератором за 5 секунд вместо 5 минут работы устройства.

## Показатели

| Показатель | Норма | Единицы |
|---|---|---|
| Глюкоза | 3,9–6,1 | ммоль/л |
| Холестерин | 3,0–5,2 | ммоль/л |
| Триглицериды | 0,5–1,7 | ммоль/л |
| Гемоглобин | 120–160 | г/л |
| Мочевая кислота | 210–420 | мкмоль/л |
| С-реактивный белок | 0–5 | мг/л |

## Экраны

1. **Home** — приветствие, кнопка «Начать анализ», сводка последнего
   измерения, карточки 6 показателей с трендом, график глюкозы (fl_chart).
2. **Measure** — пульсирующая капля крови, прогресс-бар 5 секунд,
   стадии анализа.
3. **Result** — 6 показателей с нормами и статусами, блок
   «Рекомендация ИИ» (правила: глюкоза > 6,1, холестерин > 5,2,
   СРБ > 5 и др.), сохранение в историю.
4. **History** — список измерений, тап открывает полный результат.

## Архитектура

```
lib/
├── main.dart                        # точка входа, AppState (ChangeNotifier), фрейм, навигация
├── models/measurement.dart          # модель измерения, нормы (Norms), статусы
├── services/
│   ├── recommendation_service.dart  # ИИ-правила (синхронизированы с smartblood-ai/recommendations.py)
│   ├── simulator_service.dart       # генератор измерений и демо-история (аналог Random из ТЗ)
│   └── history_storage.dart         # shared_preferences, ключ smartblood.history.v1
├── screens/                         # home / measure / result / history
├── widgets/status_badge.dart        # бейдж «Норма / Высокий / Низкий»
├── theme/app_theme.dart             # токены: #0A2540, #00C48C, #FF4D4F, радиусы 16
└── utils/format.dart                # русские даты и числа без intl
```

## Запуск

```bash
cd flutter_app
flutter pub get
flutter run -d chrome   # веб-демо, или -d <device-id> для мобильных
```

Требуется установленный Flutter SDK 3.24+ (Dart ^3.5.0).

## Ограничения MVP

- Измерение имитируется (5 секунд), реальный оптический сенсор не подключён.
- ИИ-рекомендации — детерминированные правила из ТЗ, не ML-модель.
- История хранится локально на устройстве (shared_preferences).
